# Visualização Estratégica: Dashboard Looker Studio

Este diretório documenta a interface de inteligência de ameaças (CTI) construída para o Projeto WALL-E. O dashboard traduz os logs gerados pelo motor de segurança em métricas visuais, provando a eficácia do modelo híbrido de defesa.

## Estrutura Analítica do Relatório

O relatório visual espelha a evolução investigativa do projeto, dividindo-se nas seguintes visões:

*   **Portal Axiom:** Ponto de entrada. Estabelece o contexto do "Dilema do Agente Confiável", define o objetivo do protocolo de defesa e centraliza a navegação.

*   **Protocolo de Vigilância (V1) | Paranoia:** Evidencia o impacto de um filtro mal calibrado. Mostra uma alta taxa de bloqueios rígidos e falsos positivos, gerando atrito e quebra na experiência do usuário.

*   **Protocolo de Equilíbrio (V2) | Otimização:** Apresenta a redução de falsos positivos através da recalibragem do motor. O sistema passa a realocar anomalias de baixo risco para a categoria "Suspicious", restaurando a conveniência.

*   **Veredito Cerberus (V3) | Homologação:** O painel definitivo sob um cenário de estresse massivo. Confirma a estabilização do sistema com 26% de logs suspeitos encaminhados para triagem humana, garantindo proteção robusta sem interromper a fluidez operacional.
